### What I've built

**Reconova Revenue Assurance** ([repo](https://github.com/TristanBrian/revenue-assurance)): team project, 1st place at the KPC hackathon (Inuka Fellowship). Revenue reconciliation and fraud detection for Kenya Pipeline Company, with a tamper-evident audit trail anchored on Base via Merkle trees and a Solidity contract. I worked on the backend and blockchain layer.

**Flowguard** ([repo](https://github.com/Obunde/Flowguard_Backend) · [live demo](https://flowguard-frontend.onrender.com/)): team project, Inuka Fellowship capstone. A multi-tenant predictive maintenance platform for Kenya Pipeline Company's pump network, with an ETL pipeline, ML failure-risk models, alerts and work orders, JWT/RBAC auth and tenant isolation. Built with FastAPI, PostgreSQL, Next.js and Docker.

**Mavuno Pay**: on-chain USDC escrow and supply-chain traceability on Base, linking M-Pesa payments to smart contracts through Coinbase CDP server wallets. (Private repo, demo available on request.)

**Aminia dApp** ([repo](https://github.com/Obunde/Aminia-Web3)): supply-chain tracking app with a React frontend integrating Web3 wallets and smart-contract calls.
